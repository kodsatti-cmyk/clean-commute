# How to Push to GitHub - Authentication Required

Your code is ready to push! But GitHub needs authentication.

## Option 1: Using Personal Access Token (Recommended)

1. **Get a Token**:
   - Open: https://github.com/settings/tokens
   - Click "Generate new token" → "Generate new token (classic)"
   - Note: "Clean Commute Challenge"
   - Expiration: 90 days (or your preference)
   - Scopes: Check ✓ "repo" (full control of private repositories)
   - Click "Generate token"
   - **COPY THE TOKEN** (you won't see it again!)

2. **Push with Token**:
   Run this command:
   
   git push -u origin main

   When prompted:
   - Username: kodandareddy
   - Password: [PASTE YOUR TOKEN HERE]

   The token replaces your password!

## Option 2: Using GitHub CLI (if installed)

gh auth login
git push -u origin main

## Option 3: Using SSH (More Secure)

1. Generate SSH key:
   ssh-keygen -t ed25519 -C "kodsatti@users.noreply.github.com"
   
2. Copy your public key:
   cat ~/.ssh/id_ed25519.pub
   
3. Add to GitHub:
   - Go to: https://github.com/settings/keys
   - Click "New SSH key"
   - Paste the key
   
4. Change remote to SSH:
   git remote set-url origin git@github.com:kodandareddy/clean-commute.git
   
5. Push:
   git push -u origin main
