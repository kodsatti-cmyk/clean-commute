## 🔧 Troubleshooting

### "I can't scan the QR code"

**Solutions**:
- Make sure QR code is well-lit
- Try holding phone 6-12 inches away
- Use phone's native camera app
- If still fails, manually visit: clean-commute.vercel.app/log

### "Form submission says error"

**Check**:
1. All fields filled out?
2. Kilometers is a number (not text)?
3. Try refreshing the page
4. Check if internet is connected

**If persistent**:
- Check Vercel logs for errors
- Test on different device/browser
- Contact admin

### "Dashboard not updating"

**Solutions**:
- Refresh the page (Ctrl+R or Cmd+R)
- Clear browser cache
- Wait 1-2 minutes and try again
- Check if entries are actually submitting

### "QR code goes to wrong location"

**This means**:
- QR codes need regenerating
- Visit /admin/qr
- Download fresh codes
- Print and replace
